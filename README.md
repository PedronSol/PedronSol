# Olá, eu sou o Pedro Nelson 👋

Sou estudante de Engenharia de Computação na Universidade Federal do Rio Grande do Norte (UFRN) com foco de pesquisa e desenvolvimento voltado para as áreas de **Inteligência Artificial**, **Machine Learning** e **Ciência de Dados**. 

Busco aplicar conceitos de computação inteligente, otimização matemática e arquitetura de dados para resolver problemas complexos do mundo real, unindo engenharia de hardware e software.

## Áreas de Atuação e Estudo
- **Inteligência Artificial & Machine Learning:** Desenvolvimento de modelos preditivos, análise exploratória de dados e algoritmos de aprendizado de máquina.
- **Otimização & Computação Evolutiva:** Modelagem de soluções complexas utilizando Algoritmos Genéticos e Lógica Fuzzy para problemas de alocação de recursos.
